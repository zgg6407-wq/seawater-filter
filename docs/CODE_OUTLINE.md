# 代码内容大纲

## 1. 行情与候选线
`data.py` 提供合成 OHLCV、CSV 校验、滚动 ATR；`lines.py` 按左右窗口识别高低点，确认后组合支撑与阻力候选线。每条线有 ID、两锚点、可用时间与不可变历史特征。

## 2. 线质量学习
`mature_labels` 等待 horizon 后生成生存标签和截断有效期；`learning.py` 排除分割点前未成熟样本，用逻辑回归评估期限内生存评分，用 Ridge 预测截断期限。Brier、常数基线、AUC 和期限 MAE 在留出集上报告。预测分数不宣称已校准。

## 3. 策略与回测
`Scorer` 是评分扩展协议；`LineBounceStrategy` 提供通用支撑反弹示例。`run_backtest` 按 bar 推進、下一根开盘进入，按固定止损/目标/时限退出；加入手续费、滑点、仓位预算与回撤统计。规则基线与 ML 只更换评分器。

## 4. 报告与 CLI
`cli.py` 将数据、候选线、训练和回测串联；`reporting.py` 输出含来源/版本/数据摘要的 JSON，以及 Markdown、HTML 和 SVG。

## 5. AI 扩展接口
`api.py` 是回环地址认证 HTTP 工具接口，提供报告读取和受限任务登记。不是 LLM Agent，不自动执行任务。任务持久化 SQLite，未提供命令执行、交易或模型晋级权限。

## 6. 验证与交付
`tests` 验证候选线前缀不受未来改动影响、训练不消费未来标签、下一根开盘成交、成本和盘内歧义、API 认证和任务权限。CI 在 GitHub push / PR 时自动运行测试和合成演示。

## 7. 未完成范围
真实公开数据有效性验证、概率校准、多轮 walk-forward、生存分析、自动任务执行和公网部署未实现；也没有实盘/交易所 Demo 连接。当前定位为可运行的线质量研究原型。
